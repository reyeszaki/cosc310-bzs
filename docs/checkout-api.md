Checkout and orders - backend integration

These are the five Python files proposed in chat, packaged for review.
They are not a standalone application. Use them with the existing project,
merged account code and the configured cart service from PR #91.

To register the routes in app/main.py:
    from app.api.routers import orders_routers
    app.include_router(orders_routers.router)

This integration includes the cart price conversion in _cart_with_totals:
    line_total = Decimal(str(item.price)) * quantity

The order repository creates data/orders.json when it first saves an order.
Do not overwrite an existing orders file with an empty file.

Endpoints:
    POST /checkout (bearer token, no request body)
    GET /orders
    GET /orders/{order_id}

No frontend, payment processing, tax or delivery fees are included.
Separate cart/order writes are not a transaction. A failed cart clear can
leave both a saved order and the original cart. Simultaneous checkouts and
retries are not protected and can duplicate orders or overwrite data.
